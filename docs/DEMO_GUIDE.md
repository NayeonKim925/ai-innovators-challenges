# REPLAN 데모 가이드

작업공간은 6단계를 순서대로 진행합니다: **개요 → 일정 → 변경 → 대응안 → 실행 → 이력**. 각 화면에서 진하게 강조된 버튼이 지금 누를 버튼이고, 위쪽 단계 표시는 보고 있는 결과의 진행 상태를 보여줍니다. 에이전트는 네 곳에 있습니다: **일정** 화면의 등록 시 위험 브리핑, **변경** 카드의 변화 자동 추리기, **대응안** 화면의 '에이전트로 숨은 위험 조사'와 접힌 '에이전트 설명'. 세 에이전트가 함께 쓰는 **리스크 대장**은 **개요** 화면에 있습니다. 전체 요약은 [인수인계 문서](HANDOFF.md)에 있습니다.

## 준비

```cmd
scripts\demo.cmd
```

(macOS·Linux: `scripts/demo.sh`) 평소 스택을 멈추고(데이터는 유지) 별도의 깨끗한 데이터로, 녹화된 LLM 응답을 재생하는 모드(`REPLAN_LLM_MODE=replay`)로 띄웁니다. 키·비용 없이 에이전트가 동작하며 화면 위쪽에 "에이전트 켜짐 · 녹화본 재생 중(비용 0)"이 보입니다. "에이전트 꺼짐"이 보이면 이 스크립트로 다시 띄우세요. 다음에 깨끗하게 다시 시작하려면 `docker compose -p replan-demo down -v` 후 스크립트를 다시 실행합니다.

`http://localhost:3000` → **데모 보기 → 워크스페이스 열기 → 프로젝트 만들기**(이름은 자유) → **일정**에서 **hero 데모 기준 일정 연결**(64개 작업).

몇 초 뒤 같은 화면 위쪽에 **등록 시 위험 브리핑**이 나옵니다("규칙 + 에이전트 확인"). 1순위는 `중국산 품목 통관 · 중국 희토류 수출 허가(선적마다)`로 P-A1·P-B·P-C가 들어 있고, 빨간 줄로 "P-C: 여유 0일이라 취약합니다(주공정)"가 보입니다. 품목마다 협력사·원산지·통관·허가·도착 예정·여유가 있고, 선제 행동(예: P-C 서류 준비 상황 확인 · 2027-03-26까지), L2 사례 RS-019(기준 시점 이후 발행이라 참고만)가 붙습니다. 비어 있는 속성은 "속성 없음"으로 표시되고, 아래 줄에 속성이 빠진 작업 수가 나옵니다. **개요** 화면의 리스크 대장에는 위험 5개가 모두 '예상됨'입니다.

| # | 누를 곳 | 정상이면 보이는 것 |
| --- | --- | --- |
| 1 | **변경** → 합성 통보 목록 맨 위 '대표 데모'의 `X2 · 대표 데모 …` → **합성 통보 불러오기** | 변경 카드 **1장**(X2 협력사 통보). | 3 | X2 카드의 **해석 확인 후 영향 분석**(이 화면의 유일한 진한 버튼) | **대응안** 화면으로 자동 이동. 단계 표시 1~4 완료·5 조건 승인이 지금 할 단계. "통보 내용만 반영: 영향 없음 · 완료 2027-12-21", "대응 불필요: 현재 일정으로 목표 충족" |
| 4 | 같은 화면의 **에이전트로 숨은 위험 조사** | 몇 초 뒤 한 줄 결론 "통보에 없던 P-C도 같은 수출 허가 대상일 수 있음 · 최악 +52일 · 제출 기한 2027-02-08", 빨간 상자 **"등록 시 예상했던 위험이 발생함: R-import-licence-CN"**(신호 감지 → 발생, 등록 때 경고한 P-C 주공정 문구 포함)과 비교 카드 **통보 내용만 반영**(영향 없음) 대 **에이전트 조사 후**(P-C +52일 위험, 최악 완료 2028-02-11) |
| 5 | (선택) 접힌 **근거 문장 · 실제 기사**, **협력사 메일 초안**, **판단 기록** 펼치기 | 원문 강조와 근거 기사(CNBC 2025-10-15), 제출 기한이 들어간 메일 초안, 확인 4단계와 LLM 호출 수·비용 |
| 6 | 확인 요청 칸에 회신 내용 입력(선택) → **P-C도 해당함 · 일정 다시 계산** | "조사 결과 반영: 완료 2028-02-11 (+52일)". 계산이 끝나면 대응안 목록 맨 위에 **추천** "제어 통합·교정 집중 투입 + 시운전·통합시험 병행 준비" **2028-01-25 · 회복 17일 · 32,000,000원**이 선택된 상태 |
| 7 | 오른쪽 **확인 요청 만들기** → 조건마다 회신 근거 입력 → **확인 기록** → **이 대응안 승인** | 실행 화면으로 이동 |
| 8 | **새 일정 버전 확정** → **Excel 다운로드** | 확정 버전 카드, 단계 표시 6단계 모두 완료, `replan-….xlsx`의 '변경 일정' 시트 마지막 완료일 2028-01-25 |
| 9 | **개요** → 리스크 대장의 R-import-licence-CN → **근거와 변경 이력** | 상태가 예상됨 → 신호 감지(변화 자동 추리기, N-X2 인용) → 발생(사후 조사 에이전트) → 대응 중(사람 확인) 순서로 기록됨. **사람이 상태 바꾸기**로 '종결'을 기록할 수 있음 |

### 변화 자동 추리기만 보기

합성 통보 목록 '테스트용'의 `N-X2 · 합성 외부 공지`만 불러오면 공지 카드가 따로 생깁니다. **변화 자동 추리기**가 규칙 후보 29개를 관련 있음 4 · 확인 필요 15로 나누고, 무관 12건은 **무관 12건 제외 · 이유 보기**에 접습니다. 확인 필요 작업은 체크한 것만 **에이전트로 조사**의 계산 대상에 들어갑니다. 조사는 자동으로 시작하지 않습니다.

아래 시나리오는 회귀 테스트·평가용이며 합성 통보 목록의 '테스트용' 묶음에서 불러올 수 있습니다.

| 자료 | 내용 |
| --- | --- |
| H01~H08 | 협력사 통보 원본. H02 규제 언급(조건부로만 남김), H06 완료일 미정(질문), H07 연락처만 변경(영향 없음), H08 정정 통보 |
| V01~V11 | 표현 변형. V08처럼 작업 번호가 없으면 에이전트가 원문 인용과 함께 후보를 제시하고, 사람이 **영향 작업과 날짜 지정** 후에만 계산 |
| X1-A | EU 역외 설치·시운전 기술자 취업 허가 확인 공지(근거 RS-001). 자동 추리기가 후보 26개를 확인 필요 9 · 무관 17로 나누고(관련 있음 0), 조사는 계산할 작업이 없어 독일(EU) 협력사 작업 T047·T054를 빼고 어느 작업에 비EU 기술자가 오는지 묻고 멈춤(M4) |
| X1-B | 헝가리 인허가 처리 지연(최대 45일). 자동 추리기가 T013을 관련 있음, T008·T012·T029·T057을 확인 필요로 둠. 조사는 T013만 계산해 여유 168일로 흡수, 알림 없이 "완료일 영향 없음 · 기록만"(M2). 확인 필요 작업은 사람이 고르면 함께 계산 |
| X2-대조 | 사유(시험 인력)가 달라 N-X2와 연결하지 않음("관련 없음 · 기록만"). 사유가 겹치지 않는 공지는 통보 카드에 합치지 않고 별도 카드로 남음 |
| `REPLAN_demo_inputs.xlsx` | 일정 → Excel 파일 선택 → 업로드·미리보기 → 기준 일정 확정. 변경 이벤트 행은 자동 등록되지 않으므로 원문을 붙여 넣음 |
| 외부 변화 감시 | 변경 화면 아래 '외부 변화 감시'에서 제안 수락·제외 후 활성화. 감지된 공지는 변화 자동 추리기가 1회 분류(별도 일일 한도)하고, 조사·분석은 사람이 시작할 때만 실행. 무엇을 가져오는지는 [인수인계 문서](HANDOFF.md#외부-변화-감시가-가져오는-것) 참고 |

녹화된 흐름 11개(등록 시 브리핑, H04, H02, V08, 외부 공지, 공휴일, X2, X2-대조, X1-A, X1-B, X2 확인 후 재계산)는 `python scripts/agent_flows.py --mode replay`로 비용 없이 재생해 확인합니다. 에이전트 모드별 차이:

| 모드 | 설정 | 동작 |
| --- | --- | --- |
| 에이전트 꺼짐 | 기본(키 없음 또는 `REPLAN_PAID_CALLS_ENABLED=false`) | 통보 내용과 계산기만. 화면 위쪽에 "에이전트 꺼짐"과 켜는 방법(`scripts\demo.cmd`) 표시 |
| 재생 | `REPLAN_LLM_MODE=replay` | 녹화된 응답으로 에이전트 동작, 비용 0. 녹화와 다른 요청은 멈춤 |
| 실제 | 키 + `REPLAN_PAID_CALLS_ENABLED=true` | 등록 시 브리핑(에이전트 확인 최대 3회), 감지된 공지의 자동 추리 1회(별도 한도), 작업·날짜 없는 통보 해석 1회, 정식 분석 설명 1회, 사람이 시작한 조사(최대 6회). 잠정 분석은 LLM 없음 |

고급 설정(실행 화면 아래: 협력사 휴무일, 공개 피드, 메일·알림 연결 등)의 연동 여부는 화면에 `분석에 반영`·`저장만`·`미연동`으로 표시됩니다.
